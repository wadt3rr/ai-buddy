# Тестирование

Для тестов используются Vitest, React Testing Library, user-event и jsdom. HTTP-запросы перехватывает MSW. Его обработчики подключаются в тестовом окружении.

## Запуск

Команды выполняются из каталога `frontend`.

```powershell
npm.cmd run test
npm.cmd run test:watch
npm.cmd run test:coverage
```

Дополнительные проверки

```powershell
npm.cmd run typecheck
npm.cmd run lint
npm.cmd run build
```

## Проверяемые сценарии

| Область | Сценарии |
| --- | --- |
| Авторизация | Вход, восстановление сессии, локальный выход, обработка 401, повторная проверка сессии |
| История | Первая и следующие страницы, порядок сообщений, удаление дубликатов, завершение пагинации |
| Загрузка | Защита от параллельных запросов, ошибки и повторная попытка, сброс истории при смене пользователя |
| Сообщения | Отправка, получение ответа, сохранение пользовательского сообщения при 502, отмена ожидания, следующая отправка |
| Прокрутка | Начальная позиция после загрузки, отправка из старой истории, сохранение позиции при пагинации, изменение высоты ответа |
| Интерфейс | Формы, защищённые маршруты, Markdown, копирование ответа, меню пользователя и темы |

Для проверки прокрутки размеры элементов задаются в jsdom. Рост потокового ответа проверяется обновлением текста сообщения и вызовом ResizeObserver. Сам backend SSE не предоставляет. Отдельные unit-тесты SSE-парсера сохранены в `src/api/sse.test.ts`, парсер находится в `src/test/sse.ts`.

## Покрытие

Покрытие собирается провайдером V8. Порог покрытия строк — 80,01%. В расчёт входят исходники приложения, компоненты и точка входа. Исключены тесты, тестовые обработчики MSW, вспомогательные файлы из `src/test` и декларации типов.

После `npm.cmd run test:coverage` HTML-отчёт доступен в `coverage/index.html`, сводка — в `coverage/coverage-summary.json`.

# SDD · Помощь при первом запуске сервиса

## Цель и сценарий

Стажёр описывает проблему запуска. Система находит доступную документацию,
показывает проверяемую инструкцию либо создаёт обращение наставнику.
Расхождение источников дополнительно регистрируется для владельцев документации.

## Подготовка знаний

1. Источники имеют сервис, ревизию, владельца и разрешённые роли.
2. При индексации Qwen извлекает факты `python_version`, `postgres_version`,
   `launch_command`, `access_procedure` с дословными цитатами и source ID.
3. Схема JSON, цитата, значение и source ID проверяются программой.
   Отдельные неподтверждённые факты исключаются. Полностью неверный ответ
   повторяется один раз; при повторной ошибке прежний индекс сохраняется.
4. Индекс хранит модель, версию промпта, дату, usage и SHA-256 каждого документа.
5. Изменение текста или метаданных делает запись индекса недействительной.
6. Запрос пользователя не вызывает LLM: он использует индекс и чтение явных
   параметров из документов. Подготовка индекса и интерактивная задержка измеряются отдельно.

## Контракты и права

- Браузер → `POST /api/v1/messages`, JWT, `{content}`.
- Go проверяет JWT, читает роль из PostgreSQL, сохраняет вопрос и передаёт
  до 20 сообщений в хронологическом порядке в Python `POST /generate`.
- Внутренний запрос: UUID `request_id`, UUID `user_id`, роль `intern|mentor`,
  `messages=[{role:user|assistant,content}]`. Обязателен service bearer token.
- Python проверяет каталог и роли документов до чтения их фактов/выдачи текста.
  Закрытый источник не включается в ответ, обращения или доступные пользователю данные.
- Ответ Python: `content,status,mode,sources,conflicts,tickets,latency_ms,indexed_documents`.
  Go сохраняет `content`, включая ссылки, статус и номера обращений.
- `GET /api/v1/ai/sources/{id}` повторно проверяет роль пользователя из БД.
- `GET /api/v1/ai/tickets` возвращает только обращения текущего пользователя.
- Внутренние Python, PostgreSQL и Ollama не публикуются на внешних портах.

## Правила решения

| Условие | Результат |
|---|---|
| Не указан один известный сервис | Уточнение сервиса и ошибки |
| Нет доступа к сервису | Обращение наставнику; закрытые документы не читаются |
| Источники согласуются, команда запуска найдена | Инструкция и источники |
| Версии расходятся, есть манифест той же ревизии | Выбор подтверждённой версии и задача владельцам документации |
| Конфликт без подтверждения | Задача по документации и обращение наставнику |
| Нет команды, вопрос вне области или «не помогло» | Обращение наставнику |

Большинство копий и свежесть не являются доказательством истинности.
Конфликт команды запуска не разрешается автоматическим выбором документа.
«Решено» означает найденную инструкцию; фактический успех подтверждает пользователь.
Модель и сервис не исполняют команды из документов и не меняют права доступа.

## Обращения и наблюдаемость

Создание обращения — результат обращения пользователя в первую линию.
SQLite сохраняет ID, пользователя, тип, статус, время, вопрос, сервис, причину,
проверенные источники и расхождения. Дедупликация по request_id защищает от
повторного вызова, для документации — по пользователю/сервису/ревизии/конфликту.
Журнал `tickets.jsonl` атомарно экспортируется из БД и восстанавливается при
запуске. Ошибка экспорта не отменяет уже сохранённую в SQLite заявку.
UI показывает номера в ответе и список в панели «Обращения».

## Ошибки и отзывчивость

UI сразу отображает отправленный вопрос и индикатор ожидания. Панель обращений
и история доступны независимо. Невалидный/устаревший индекс не используется;
доступные явные факты обрабатываются правилами. Ошибка Python-сервиса даёт
Go 502: вопрос остаётся сохранённым, пользователь видит ошибку.
Ориентир локальных действий — <1 с; сетевые/модельные операции имеют отдельные
измерения и обработку отказов. Таймауты Go/HTTP/nginx ограничивают время ожидания.

## Приёмка

`listing-search` → Python 3.12 по манифесту v2.0, расхождение с Confluence,
задача по документации. `notifications-service` → нет доступа, наставник.
`billing-service` → конфликт без опоры, наставник. «Не помогло» → наставник.
Запрет утечки, подмена роли в тексте, выдуманные цитаты, старый индекс,
перезапуск, повтор request_id, восстановление журнала проверяются тестами.

Проверки: `ai_service/tests/`, `backend/integration/`, тесты UI,
`scripts/smoke.py`, `ai_service/evaluate.py`.

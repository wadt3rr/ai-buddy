## Задержка и подготовка знаний

Полная HTTP-цепочка Go → PostgreSQL → Python в отдельном режиме `indexed`,
30 последовательных запросов: **p50 6.744 мс, p95 11.023 мс, максимум 16.856 мс**.
Это локальный прогон; сетевые и аппаратные условия другой среды отличаются.
Сохранённый результат — `E2E.json`.

Индекс получен реальным запуском `qwen3:4b-instruct-2507-q4_K_M` через Ollama 0.40.16
на CPU, без GPU: 6 документов, 2 вызова,
1187 токенов.
1 неподтверждённый факт отклонён проверкой.
Содержимое и происхождение индекса — `../ai_service/data/facts.json`.

В режиме `llm` каждый интерактивный запрос вызывает Qwen с вопросом, историей,
разрешёнными фрагментами и проверенными фактами. Прогон 10 сценариев на CPU:
**медиана 13.482 с, максимум 33.664 с**; все ответы получены моделью, без fallback.
Отчёт — `EVALUATION-LIVE.json`. Для режима `indexed` сохранён отдельный
`EVALUATION.json`; его задержки нельзя считать задержками генерации.

Модель выбирает ID разрешённых источников по JSON schema; выдержки копирует
код. Корректность ID и наличие выдержек не доказывают все выводы свободного
текста. При ошибке API или формата ответ явно помечается как резервный;
`llm_used=false`. Статусы, права и реальные записи заявок контролирует код.

Сквозная проверка нового режима через настоящий Go API, PostgreSQL, Python
и Ollama также проходит: вход по JWT, два сообщения с общей историей,
генерация обоих ответов моделью, запрет закрытого источника, сохранение
истории и заявок. Два HTTP-запроса заняли 9.149 и 10.164 с на прогретой модели.
Отчёт — `E2E-LIVE.json`. Это запуск процессов напрямую, без Docker и nginx.

## Надёжность

Проверяются выдуманные цитаты/значения/source ID, повреждённый и устаревший
индекс, повтор request_id, изоляция пользователей, сохранение и восстановление
журнала обращений, миграция прежней SQLite-схемы, ошибки HTTP и авторизации.
Копии документов и их дата не устанавливают приоритет без подтверждения
манифестом соответствующей ревизии.

SQLite — основное хранилище обращений. `tickets.jsonl` восстанавливается
из него; ошибка экспорта не уничтожает сохранённую заявку. Панель обращений
загружается с JWT и обновляется после завершения ответа.
